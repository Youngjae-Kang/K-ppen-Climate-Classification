위키 기후 그래프 메이커 v2

도시의 Wikipedia 페이지를 읽어 기후표에서 월별 평균 기온·강수량을 자동 추출하고, 고정된 교재용 기후 그래프로 다시 그립니다.

1. 위키피디아 페이지

도시 페이지 URL이나 문서명을 입력해 주세요.

2. 기후표 선택

사용 행 정보가 여기에 표시됩니다.

3. 12개월 데이터 확인·수정

기온 우선순위: Daily mean / 평균 기온 → 없으면 평균 최고·평균 최저의 평균으로 근사.
강수량 우선순위: Average precipitation → 없으면 Average rainfall.
월기온 ℃강수량 mm

4. 그래프 디자인

강수량이 450mm를 넘으면 축을 늘리지 않고 막대 위에 생략 표시를 자동으로 넣습니다.
Wikipedia 데이터가 로드되면 출처와 추출 방식을 표시합니다.
